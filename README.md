# Skeledok

**Skeledok** is a digital twin tool divided into a client and a server. This tool helps to serve gemeente Leeuwarden in their attempt to create a digital twin of "Spoordok".

## Getting Started

### Prerequisites

Ensure you have the following installed on your system:
- Runtime: [Java JDK 21](./doc/Java-21-help.md)
- Repository cloned (`git clone https://github.com/Ggjorven/Skeledok.git`)

### Building, Testing & Running

The tool is split into a [client](./client/) and a [server](./server/). Build instructions can be found below:
- Client - [CLIENT.md](./doc/CLIENT.md)
- Server - [SERVER.md](./doc/SERVER.md)

Supported platforms are:
- **Windows**: IntelliJ, Eclipse, Gradle
- **Linux**: IntelliJ, Gradle
- **MacOS**: IntelliJ, Gradle
